# KuroDemo

## 项目介绍

本项目是基于 Unreal Engine 5 开发的推箱子游戏 Demo，主要实现了关卡游玩、关卡选择、关卡编辑与试玩验证等功能。

项目围绕经典推箱子玩法展开，玩家需要推动箱子到指定目标点完成关卡。游戏支持多个关卡数据的读取与切换，并提供关卡编辑器用于创建、修改和验证关卡布局。关卡编辑器中可以放置墙体、玩家出生点、箱子和目标点，并支持合法性检查、试玩验证和保存关卡等操作。

## 主要功能

- 推箱子基础玩法
  - 玩家按方向键移动
  - 箱子可被推动
  - 墙体阻挡玩家与箱子移动
  - 所有箱子到达目标点后判定通关

- 关卡选择系统
  - 支持多个关卡显示
  - 支持已解锁 / 未解锁状态区分
  - 通关当前关卡后解锁下一关
  - 支持从关卡列表进入指定关卡

- 关卡编辑器
  - 支持自定义地图尺寸（3*3-20*20）
  - 支持放置墙体、玩家出生点、箱子、目标点
  - 支持橡皮擦清除已放置物体
  - 支持关卡合法性检查
  - 支持试玩验证
  - 支持保存关卡数据

- UI 交互
  - 主菜单
  - 关卡选择界面
  - 游戏 HUD
  - 通关弹窗
  - 关卡编辑器工具栏

## 项目入口

### 主地图入口
直接点击Play，或进入KuroDemo\Content\MyProject\Maps\M_Main场景后点击Play。
### 关卡编辑器入口
进入游戏后，点击主菜单关卡编辑器按钮进入。

## 操作说明

### 1. 主菜单操作

运行项目后进入主菜单界面，玩家可以根据界面按钮选择不同功能。

- 点击“开始游戏”：进入关卡选择界面。
- 点击“关卡编辑器”：进入关卡编辑界面。
- 点击“退出游戏”：退出当前游戏。

### 2. 关卡选择操作

进入关卡选择界面后，系统会显示当前可游玩的关卡列表。

- 已解锁关卡可以点击进入挑战。
- 未解锁关卡会显示为锁定状态，无法点击进入。
- 通关当前关卡后，系统会自动解锁下一关。
- 关卡会按照关卡 ID 从小到大排列显示。

### 3. 玩家游玩操作

进入关卡后，玩家通过键盘控制角色移动，将箱子推到目标点上完成关卡。

| 操作 | 按键 / 方式 |
|---|---|
| 向上移动 | W / ↑ |
| 向下移动 | S / ↓ |
| 向左移动 | A / ← |
| 向右移动 | D / → |
| 重开当前关 | 点击 HUD 中的“重开”按钮 |
| 返回主菜单 | 点击 HUD 中的“返回主菜单”按钮 |

当所有箱子都被推到目标点后，关卡通关，系统会弹出通关界面。

通关界面支持以下操作：

- 点击“下一关”：进入下一关。
- 点击“重开本关”：重新开始当前关卡。
- 点击“返回主菜单”：返回主菜单界面。

### 4. 关卡编辑器操作

关卡编辑器用于创建和调整推箱子关卡布局。

#### 4.1 地图生成

在关卡编辑器中，可以设置地图的基本尺寸。

- 输入关卡宽度和关卡高度。
- 点击“生成 / 重建地图”按钮。
- 系统会根据输入尺寸生成可编辑地图区域，并自动生成外围墙体。

说明：关卡宽度和高度表示可编辑区域大小，不包含外围墙。

#### 4.2 画笔选择

编辑器提供多种画笔类型，用于放置不同的关卡元素。

| 画笔类型 | 说明 |
|---|---|
| 墙体 | 放置阻挡玩家和箱子的墙体 |
| 玩家出生点 | 设置玩家初始位置 |
| 箱子 | 放置需要推动的箱子 |
| 目标点 | 放置箱子需要到达的目标位置 |
| 橡皮擦 | 清除当前位置已经放置的元素 |

选择画笔后，点击地图格子即可放置对应元素。

#### 4.3 编辑规则

关卡编辑时需要满足以下基本规则：

- 每个关卡必须有且只能有一个玩家出生点。
- 箱子数量必须等于目标点数量。
- 至少需要有一个箱子和一个目标点。
- 玩家出生点、箱子和目标点不能放在外围墙体上。
- 初始状态不使用“箱子与目标点重合”或“玩家与目标点重合”的特殊格子。

#### 4.4 合法性检查

点击“合法性检查”按钮后，系统会检查当前关卡是否满足基本规则。

如果关卡不合法，界面会给出提示信息，例如：

- 缺少玩家出生点。
- 玩家出生点数量超过一个。
- 箱子数量与目标点数量不一致。
- 缺少箱子或目标点。

#### 4.5 试玩验证

点击“试玩验证”按钮后，系统会使用当前编辑器中的关卡布局进入试玩模式。

试玩模式下可以验证：

- 玩家是否可以正常移动。
- 箱子是否可以正常推动。
- 通关条件是否可以触发。
- 当前关卡是否具有可玩性。

试玩通关后，可以通过通关界面返回关卡编辑器。

#### 4.6 保存关卡

点击“保存关卡”按钮后，系统会将当前关卡数据保存到本地关卡数据中。

保存前需要保证关卡通过合法性检查。

如果保存的关卡 ID 已存在，系统会覆盖原有关卡数据；如果关卡 ID 不存在，系统会新增一条关卡数据。

### 5. 关卡数据规则

本项目使用数字表示关卡中的不同格子类型：

| 数字 | 含义 |
|---|---|
| 0 | 空地 |
| 1 | 墙体 |
| 2 | 玩家出生点 |
| 3 | 箱子 |
| 4 | 目标点 |

### 6. 推荐运行流程

首次运行项目时，建议按照以下流程体验：

1. 打开项目主地图。
2. 点击 Play 运行项目。
3. 在主菜单点击“开始游戏”。
4. 在关卡选择界面选择已解锁关卡。
5. 完成推箱子关卡挑战。
6. 通关后进入下一关或返回主菜单。
7. 返回主菜单后，可以进入关卡编辑器创建或调整关卡。
8. 在编辑器中完成地图编辑后，点击“试玩验证”测试关卡。
9. 确认可玩后保存关卡。
